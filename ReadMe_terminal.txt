週案日誌 持ち帰り入力版

【使うファイル】
- index.html
- weekly-planOL.js
- weekly-planOL.css
- jszip.min.js
- icon-192.png
- icon-512.png
- manifest.json

【使い方】
1. GitHub Pages には、このフォルダー内のファイルを入れてください。
2. 開くファイルは index.html です。
3. 園内で「管理」→「園内PC URL」を確認します。
4. 園内で「受信」します。
5. 自宅で入力します。
6. 園に戻ったら「送信」します。

【注意】
送信時はサーバー側の同じ週データを無条件で上書きします。
