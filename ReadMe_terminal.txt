週案日誌 持ち帰り入力アプリ

【使うファイル】
offline.html
offline.js
offline.css
jszip.min.js

【使い方】
1. 端末側フォルダーに、この4ファイルを置きます。
2. offline.html を開きます。
3. 園内で、管理タブの「園内PC URL」が http://192.168.1.60:3000 になっているか確認します。
4. カレンダーで週とクラスを選びます。
5. 園内で「受信」を押します。
6. 自宅で編集します。自動で端末内に保存されます。
7. 園に来たら、同じ週とクラスを開いて「送信」を押します。

【重要】
・送信時は、サーバー側の同じ週・同じクラスのデータを無条件で上書きします。
・自宅ではサーバーに接続できなくても編集できます。
・同じ週を複数人で同時編集する運用には向きません。
